# UI assets

`archive-forest.png` is original OpenAI-generated artwork created for the approved
fantasy design study on 2026-10-22. It depicts an invented elven traveler and a
ruined forest gateway. It is decorative interface art, not established Pathfinder
canon or an asset in the user's comic project. The Docker build and local runner copy it into the public output
and does not request third-party images or fonts.
